## ❌ Критические проблемы

### 1. Отсутствуют связи в модели Sale ⚠️ КРИТИЧНО
**Файл:** `app/Models/Sale.php`

**Проблема:**
```php
// Есть только это:
public function shopper(): BelongsTo
{
    return $this->belongsTo(Shopper::class);
}

// Отсутствуют:
// - public function cashier()
// - public function shift()
```

**Влияние:**
- Невозможно использовать eager loading для cashier и shift
- N+1 запросы при получении связанных данных
- Неудобный API для разработчиков

**Решение:** Добавить 2 метода в модель (см. SALE_API_FIXES.md)

---

### 2. Неправильные Foreign Keys в миграции ⚠️ КРИТИЧНО
**Файл:** `database/migrations/2026_01_25_000002_create_sales_table.php`

**Проблема:**
```php
// Текущий код:
$table->integer('cashier_id')->nullable();
$table->integer('shift_id')->nullable();
$table->integer('shopper_id')->nullable()->index();

// Должно быть:
$table->foreignId('cashier_id')->nullable()->constrained()->nullOnDelete();
$table->foreignId('shift_id')->nullable()->constrained()->nullOnDelete();
$table->foreignId('shopper_id')->nullable()->constrained()->nullOnDelete();
```

**Влияние:**
- Нет referential integrity
- При удалении кассира/смены продажи останутся с битыми ссылками
- Нет автоматических индексов
- Невозможен CASCADE DELETE

**Решение:** Создать миграцию для исправления FK (см. SALE_API_FIXES.md)

## ⚠️ Средние проблемы

### 3. Отсутствует валидация cashier_id, shift_id, shopper_id
**Файл:** `app/Http/Controllers/Api/SaleApiController.php`

**Проблема:**
```php
// Текущая валидация НЕ включает:
'cashier_id' => ...
'shift_id' => ...
'shopper_id' => ...
```

**Влияние:**
- Можно указать несуществующий ID
- Нет проверки exists в БД

**Решение:** Добавить в валидацию (строки 71-105)

---

### 4. Нет проверки total_price 💰
**Проблема:**
Можно передать любое значение total_price, даже неправильное:
```json
{
  "items": [
    {"product_id": 1, "quantity": 2, "price": 1000}
  ],
  "total_price": 999999  // Должно быть 2000, но проверки нет!
}
```

**Влияние:**
- Риск финансовых расхождений
- Ошибки в отчетности

**Решение:** Автоматически рассчитывать total_price (см. SALE_API_FIXES.md)

---

### 5. Нет проверки наличия товара на складе 📦
**Проблема:**
Можно продать товара больше, чем есть на складе:
```json
{
  "items": [
    {"product_id": 1, "quantity": 999999, "price": 1000}
  ]
}
```

**Влияние:**
- Отрицательное количество на складе
- Невозможность отследить реальные остатки

**Решение:** Добавить проверку перед созданием (см. SALE_API_FIXES.md)

---

## 📝 Незначительные проблемы

### 6. Нет eager loading в index()
**Влияние:** N+1 запросы, медленная работа при большом количестве продаж

**Решение:**
```php
$query = Sale::query()->with(['shopper', 'cashier', 'shift']);
```

### 7. Недостаточно фильтров
**Влияние:** Неудобно искать продажи по кассиру, смене, покупателю

**Решение:** Добавить фильтры (см. SALE_API_FIXES.md, строки 23-40)
